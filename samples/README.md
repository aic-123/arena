# 分割质量样本（`§C5.5.1`）

**这是什么**：`§C5.5.1` 要求的人工标注小样本，用来给「切分数一致率」「边界一致率」两个数做参照物。

**纪律（`§C5.5.1` 第 2 条，硬约束）**

> 标注**不由 AI 生成**。由需求方标注或确认——**不能让 AI 同时充当被评估者和评估者**。

所以本目录下 `.md` 文件里的 `annotation` 区块**只能由需求方填写或确认**。
`agent_filled` 字段记录每一条的标注来源。凡是标 `未标注` 的，一律不计入统计。
**`checks.py` 的 B8 与 B13 机械保证这一点**（见下）——
B8 管「声明待标注的块，标注区必须空」，B13 管「有值的块，必须说清值是谁填的」。

样本条数：**20**。
依据：`§C13.1` 第 4 项 —— 这个数在文档里被明确标为「`拍`，无依据」，且「已从正文移除，条数自定」。
**这是文档唯一真正交给 agent 的自由项。** 我取 20，理由是量级够跑一致率又不至于拖死每轮回归。
**它没有依据，你可以改。**

### B8 在这份文件上不再适用 —— 补了 B13

`checks.py` 的 **B8** 扫描 `samples/*.md`：
**自己声明了 `annotation_status: 待需求方标注` 的区块，标注区必须是空的。**

**2026-09-25：折算之后，B8 在这份文件上没有可罩的区块了。**
`inputs.md` 里 20 条的 `annotation_status` 全部离开了 `待需求方标注`，
于是它在这份文件上一条都罩不住 —— **而它照样打印「过」**。

**这不是 B8 坏了，是流程往前走了一步。** 它的判据、实现、验伪注入全都还对
（往 `0019` 块注入一个值，它照样命中、退出码 1；还原，退出码 0），
而且它**现在仍然罩着别的文件**。
**一个检查在某个文件上不再适用，和它失效，是两回事。**
它背后的约束也没有被破坏：`§C5.5.1` 第 2 条允许「需求方标注**或确认**」，
折算走的是「确认」那一支，逐条留了 `agent_filled` 出身。

留下来的那条教训仍然成立，但它说的是**检查**，不是 B8 有错：
靠标记触发的检查，标记一走就静默空转，**而空转和通过长得一模一样**。
所以补上另一半覆盖 —— **B13**：`annotation_status` 不是待标注、且 `proposed_count` 有值的块，
**必须同时有 `agent_filled`**（值是谁填的，得说）。
两块地不重叠：待标注的块归 B8，有值的块归 B13。

验伪各一次，正反两向：
- B8：往 `0019` 块注入 `proposed_count: 2` → 命中，退出码 1；还原 → 0。
- B13：造一个「有值、没署名」的块 → 命中，退出码 1；补上 `agent_filled` → 0。
  （两条都在 `test_checks.py` 里有专门用例，不是只看「过」。）

（口径与 `DECLARATION.md` §11 一致 —— 那一节的上一版把这件事写成了「风险 / 出事」，
**报大了**，已更正。）

## 每条要标注什么

只要两项（`§C5.5.1` 第 1 条）：

1. **这条输入包含几个命题**（一个整数）
2. **每个命题的边界**（在原文里的起止，用 `[起:止]` 字符下标表示）

不要标注「哪个切法更好」「这句话对不对」——那不属于本样本，
且「意义是否被歪曲」是 `§C2.3` 禁止 AI 做的判断。
